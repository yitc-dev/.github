# Security policy

Please report a security vulnerability **privately**, never in a public issue or discussion.

- Use the repository's **Security** tab → **Report a vulnerability** (private vulnerability reporting).
  For the kernel itself, report it on https://github.com/yitc-dev/yitc.
- Say what is affected, how to reproduce it, and what you think the impact is. Do not include real
  credentials or customer data; a minimal reproduction is enough.
- Write in any language.

We answer in the private report. Once a fix is released, we may publish an advisory that credits you,
if you want to be credited.

A key compromise or a release signature that fails to verify is a security matter too: report it the
same way.
